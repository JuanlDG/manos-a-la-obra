# Manos a la Obra

Gestión de trabajos solidarios de construcción: materiales, herramientas y voluntarios.

## Ejecutar localmente

    npm start

Abrir http://localhost:3000

## Despliegue en Railway

New Project → Deploy from GitHub repo → seleccionar este repositorio. Railway detecta `npm start` y usa la variable `PORT`.

Nota: los datos se guardan en el `localStorage` del navegador de cada usuario (no hay base de datos compartida todavía).
